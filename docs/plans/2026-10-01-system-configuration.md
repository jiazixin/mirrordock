# 系统配置页与可编辑下载代理

用户要求将系统设置底部的配置/环境区域拆为独立系统配置页，解析展示运行环境，不输出原始 JSON；下载代理读取当前值并直接修改。

采用侧栏独立 `/admin/system` 页面，延续现有蓝色、轻边框与响应式布局。系统设置保留同步参数；相比增加设置页签或弹窗，独立页面支持直接访问与集中查阅。系统配置展示当前进程实际生效的监听、数据目录、SQLite 路径、镜像根、日志及 TLS 路径，并展示程序版本、Go、OS/架构、CPU 与启动时区。手工修改 YAML 后重新载入的待重启提示继续展示，实际运行字段来自启动配置，避免混淆。环境检查自动读取，支持重新检查，版本文本解析成版本与可用性，目录权限单独显示；DNF 检查不宣称完成 reposync 插件或发行版验收。

代理作为用户明确授权的读取例外，在受登录保护且 no-store 的配置 API 返回完整地址，设置页使用文本输入并回填；保存后保留当前值，空字符串保存清空代理。Token/管理员密码继续隐藏，代理仍不进入运行快照、审计和日志。其他页面保存不改变代理，沿用 proxy_update、revision 和 YAML 原子写回协议，不增加配置字段。

验证：构建 Web 后 Go 检查；配置 API、代理读取/修改/清空/其他页面保留、Token/密码隔离、实际启动环境与重载待重启状态；隔离浏览器 E2E 验证独立页面、可读检查结果与窄屏。实现后执行 OCR，记录覆盖、结果与未验证边界。
