# 管理列表分页与紧凑筛选

目标：批次筛选缩为桌面四个紧凑控件；管理列表统一默认 50 条，可选 20/50/100 条，支持首尾页、相邻页及输入跳页。公开镜像目录不分页。

实现：公共 Pagination 组件仅处理分页展示和交互；配置列表在前端筛选后切片；运行/批次和通知记录在服务端用 limit/offset 查询完整历史。筛选和条数变化回到首页，数量缩减自动校正页码，异步旧响应不覆盖新请求。批次继续显示 SSE 实时进度；原始日志沿用现有游标读取。

步骤：
1. 在 web/src/components 添加公共底栏，在 sources、schedules、runs、settings 列表接入；批次筛选宽度 150/180/150/150px，手机两列或单列。
2. 批次运行来源在 SQLite 查询前过滤，通知查询返回完整总数和受限分页；新增隔离数据库分页测试。
3. 公开 listing 移除分页控件和切片，保留搜索/排序、1000 项读取上限；更新对应浏览器验收。
4. 构建 Web 后编译临时测试二进制；执行 OCR 本地 preview/rule 审查，修复问题，再执行 Go 相关测试和隔离 Chromium E2E，记录 ACCEPTANCE。

保持已有视觉与配置协议；不启动案例同步，不修改用户镜像/凭证，不推送发布。外部 OCR 调用沿用已记录限制，使用已允许的本地 delegate 工作流。
