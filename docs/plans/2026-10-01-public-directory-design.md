## 项目信息与精简修订

按用户截图移除说明、分类筛选及页脚，搜索置于列表标题前方，保留文件图标、排序、搜索与分页。普通项目在实际 dest 行显示同步元数据；GitHub 仓库项目行同样显示项目状态、当前发布文件总大小、项目上次同步及下次计划，仓库内各 Release 目录只补充各自大小，沿用普通文件列表列，不展示项目状态和上次/下次同步；悬停时间可看程序时区的准确时间，未知数据用 `—`。

实施：发布阶段汇总普通公开文件字节、保存当前代摘要；GitHub 在已选附件全部验证成功后写私有版本同步标记，发布失败不影响当前代。启动兼容旧发布代，单代 Release 摘要有 1000 项上限。HTML 模板保持转义与脚本 CSP 哈希，下载不查询任务数据库或递归统计。验证覆盖项目四项信息、版本目录独立大小且不读取运行元数据、未知记录、重启、隐藏标记、搜索/排序和窄屏横向表格。
