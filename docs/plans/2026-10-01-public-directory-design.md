# 公开目录列表改版

用户选择参考图中的文件列表：浅灰背景、白色圆角表格、细分隔线、小尺寸图标、搜索和分段筛选。沿用镜像目录的 Go 服务端渲染，不引入管理端登录或外部资源。

- 显示真实的名称、文件类型、大小和修改时间；虚拟目录无文件元数据时显示 `—`。
- 文件夹优先，支持当前已列出条目的搜索、类型筛选、排序和每页 50 项的分页。
- 统一目录、RPM、DEB、归档、元数据、签名、校验和、镜像、文本及通用文件图标。
- 用户后续选定 Phosphor Icons Regular：文件图标采用官方 SVG、统一深灰和等比例尺寸，本地嵌入，保留 MIT 授权及固定提交的可复现导入脚本。
- 保留目录读取 1000 项的资源上限并明确提示；下载路径、受限文件根、HTTP Range 和文件流保持原有行为。
- 静态脚本通过 CSP 哈希授权；文件名和路径由 HTML 模板转义。无 JavaScript 时仍可浏览全部已列出链接。

验证：Go 列表与下载回归、浏览器搜索/筛选/分页/排序及视觉截图、Web 构建、OCR 本地 delegate 审查；结果写入 `docs/ACCEPTANCE.md`。
